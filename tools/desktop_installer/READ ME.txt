TamaPoke Installer
==================

Installs TamaPoke onto a Waveshare ESP32-S3-Touch-AMOLED-1.75 board, loads the
sprite packs onto its microSD card, and backs up / restores your save.

1. Keep this whole folder together: the program reads the files next to it.
2. Plug the board in with a USB data cable and open TamaPokeInstaller.exe.
   Windows may say "Windows protected your PC" because the program is not
   signed by a company: click "More info", then "Run anyway".
3. Pick the board in the list (it says "ESP32-S3 board"). If it is not there,
   hold BOOT, tap RESET, let go of BOOT, then press Refresh.
4. Type the install password you were given and press
   "Back up save, then install". Your save is backed up first, to
   Documents\TamaPoke backups, and the save area is never erased.
5. Tick the regions you want and press "Load selected packs". Kanto is the
   one to start with; each region takes a few minutes.
